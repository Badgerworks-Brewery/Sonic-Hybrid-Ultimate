HOW IT WORKS NOW
================================================================================

User Workflow:
1. Place soniccd.rsdk, sonic1.rsdk, sonic2.rsdk in rsdk-source-data/
2. Run build_all.sh (or build_all.ps1 on Windows)
3. Build automatically:
   - Detects source files
   - Builds C# generator tools
   - Unpacks and converts games
   - Merges into unified Data.rsdk
4. Run hybrid mode:
   - ./run_hybrid.sh (or run_hybrid.bat)
   - Plays Sonic 1 → CD → 2 seamlessly

If source files not provided:
- Build still succeeds
- Hybrid generation is skipped
- Clear instructions provided
- Can still play individual games
